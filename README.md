# 100 Day Python Code Challenge

A self-directed Python fundamentals challenge, working through core language concepts one day at a time. Currently at **Day 8 of 100**.

## Covered so far
| Day | Topics |
|---|---|
| 1 | Python Basics |
| 2 | Data Structures |
| 3 | Control Structures |
| 4 | Lambda, Arrays, Classes/Objects |
| 5 | Iterators, Polymorphism, Scope |
| 6 | Modules, Dates, Math, JSON |
| 7 | RegEx, Try/Except, User Input, String Formatting |
| 8 | File Handling |

## Setup

```
pip install -r requirements.txt
```

Then open any `DayN.ipynb` notebook in Jupyter.
